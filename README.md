
# All-Theme Dashboard Application

## Overview
**All-Theme Dashboard** is a modern, responsive web application designed to showcase multiple dashboard types and themes. It allows dynamic filtering, searching, and interactive data management, providing a seamless user experience. The project emphasizes complex **state management** and front-end logic for high interactivity.

---

## Features

- **Dashboard Types:** Multiple pre-built dashboard layouts (analytics, e-commerce, user stats, project management, etc.)  
- **Theme Support:** Switch between light, dark, and custom color themes easily.  
- **Filtering & Search:** Real-time filtering and search across dashboards and data entries.  
- **Interactive Components:** Tables, charts, cards, and widgets with dynamic JS logic.  
- **State Management:** Centralized and efficient state handling using Redux Toolkit or Context API.  
- **Responsive Design:** Fully responsive dashboards compatible with desktop, tablet, and mobile devices.  
- **Animations & Transitions:** Smooth UI transitions with Framer Motion or CSS animations.  

---

## Challenges Solved

1. **State Management:**  
   Managing complex state for multiple dashboards, filters, search inputs, and dynamic components.

2. **JS Logic for Interactivity:**  
   Implementing logic for filtering, searching, sorting, and dynamic updates in a performant way.

3. **Theme Switching:**  
   Real-time theme updates without reloading the page.

4. **Data Consistency:**  
   Ensuring consistent UI updates when multiple components depend on the same state.

---

## Tech Stack

- **Frontend Framework:** [React](https://reactjs.org/) / [Next.js](https://nextjs.org/)  
- **State Management:** [Redux Toolkit](https://redux-toolkit.js.org/) or React Context API  
- **Styling:** [TailwindCSS](https://tailwindcss.com/)  
- **Charts & Visualizations:** [Recharts](https://recharts.org/) or [Chart.js](https://www.chartjs.org/)  
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
